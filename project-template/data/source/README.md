# data/source/

Local **source** data for this project — **git-ignored** (nothing here is committed).

Put here:
- GIS polygons (study-area, prediction-region, and — if excluding Russian data — the Russian
  EEZ), e.g. `.gpkg` / `.shp`.
- Any legacy SPD extracts (only if `USE_SPD: true`).

The Biotic database itself is **not** here — it lives outside any repo (BAIT default
`~/IMR_biotic_BES_database/`) and is reached via BAIT's `biotic-connect`.
